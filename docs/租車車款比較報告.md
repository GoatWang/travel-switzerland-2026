## 取還車提醒

1. **取車文件**: 駕照正本、國際駕照、護照、信用卡、Avis 確認書。
2. **現場確認**: CDW/TP 自負額、額外駕駛是否免費、跨境規則、道路救援與高速公路通行證。
3. **車況檢查**: 外觀、輪胎、玻璃、輪框、內裝、油量、里程都拍照留存。
4. **還車前**: 加滿油並保留加油收據，22:00 前回 Zurich Airport 還車。
